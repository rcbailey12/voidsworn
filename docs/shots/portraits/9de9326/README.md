# Portraits: Sunward Crusade in their own settings (R68)

What to look at:
- `crusade.webp`: Vex and the six Crusade Nemesis as the game frames them, each in its own place and light.
- `crusade_scars.webp`: each Nemesis, then the same Nemesis with each scar it can earn (a burn and a blinded eye), painted onto the new picture.

What changed:
- Vex stands in a frost-rimed war room, fists on a table lit by an ember star chart.
- Nemesis 1 to 6: a frozen hangar, a furnace room, a small observation pod over an orange sun, a gun deck, a frozen corridor, a frosted bridge.
- Nemesis 3 needed three tries: the "warship deck" kept turning into a sailing ship, so it now sits in a round iron pod in deep space.
- Scars were repainted on every new picture (two tries each, the clearer one kept). There is no implant scar for the Crusade any more (R1), so those old files are gone.
- `godot/portraits/sheets/voidsworn_portraits.webp` is the phone sheet with Vex and his alternates.

Calls Ryan can veto (Claude's picks):
- Nemesis 3's pod reads as a glass lamp at full size; once the game crops it to the bust it reads as a viewport frame, so it was kept rather than drawn a fourth time.
- The burn scars read as fresh red wounds more than old healed burns on Nemesis 1, 4 and 6; they are kept because they read clearly at card size.
