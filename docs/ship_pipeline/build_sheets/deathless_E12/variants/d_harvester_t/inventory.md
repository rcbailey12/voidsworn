# E12 / d_harvester_t inventory

The core and hull use the [base inventory](../../inventory.md). The variant replaces the fore null cannon and fixed bow emitter with one turreted corona arc. Its selected slots and mounts pass [weapon matching](weapon_match.json). The base-only inventory counter expects two null cannons and flags the pre-existing projector detail tag; it is not a variant-aware acceptance check. No weapon geometry changed in issue 877.
