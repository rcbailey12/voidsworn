# Ryan's words
One file per month, `docs/words/YYYY-MM.md`: the record of what Ryan said, in his own words.
Append-only: never edit or delete a line; a correction is a new line that cites the old one.
Verbatim: copy the exact words, typos and punctuation included, with the date, time, FINDINGS row and the chat that heard them.
The chat that heard him writes the line in the same turn; no other seat writes, rewrites or tidies his words.
