Cross-pool notes
haven: The hardest variant to keep honest. The shipped event has three options, all of which either start a fight, cost credits, or carry a faction need gate. Per Ryan's Oct 28 ruling, I added a fourth option (plain "Leave," r {}) as the guaranteed free exit. This is the only structural addition in the pack.
moon: The free-exit requirement is met by "Bombard from orbit and leave" (always enabled, no need gate, r is a gain not a cost, does not start the fight). Kept as-is in the variant.
tomb: Only two options. "Chart it and leave" (+30 credits) serves as the free exit (always enabled, no cost). The fight option is clearly labelled. No issue.
astropath / shrine: These events carry faction-specific variant text blocks (the v field). I drafted the base variant only; the faction sub-variants were not re-drafted here, as the pack instructions ask for one variant per event. Flagging in case a follow-up pass is needed.
tithe: All three options carry a k tag. The "leave" option is tagged k: "leave" and has r {}. It functions as the free exit. No fight-start, so rule 4 is satisfied trivially.
saboteur: The "You know his face" option requires the defector flag. If that flag is absent the option is gated, but "Search the ship" and "Ignore it" remain always enabled. No fight-start, no rule 4 concern.
Numbers audit: All credits, percentages, experience values, and clock steps match the shipped table exactly. No sub-line number was altered.
