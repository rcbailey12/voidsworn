## Engineering items for Astra

1. **Hover freeze (#16).** Measure threat_both() and the worst frame after a move with real hulls on Ryan's PC and one
   laptop. Is a per-version cached answer enough, or should the threat map be incremental? Design one "rules client"
   that owns the worker tasks so no caller can join by accident (15 hand-kept join sites today). (Godot Q2, finding 12a.)
2. **Battle load stretch (#30).** Longest single frame in a cold battle load with real hulls; any frame over 5 s? Which
   of board.build, world.build and hull loads owns it; plan threaded loads. (Godot Q3.)
3. **Cold first launch.** Export the pinned build and count what the shader baker really bakes; does a Shader.new code
   string get anything? First launch to title and first battle on a clean Windows profile; pipeline compiles after the
   cover lifts. Does Godot 4.7 reuse a compiled shader for an identical code string each battle (Neon P5)? Fable's leg
   names issue 1334 for the first-launch race; 1334 is a merged checkout PR, so no issue tracks this yet. (Godot Q1, Q7,
   finding 5.)
4. **Other GPUs.** On a PC where Vulkan fails: does the D3D12 fallback start (export_d3d12=0 is Automatic, not off), are
   shaders baked for it, does create_local_rendering_device work on a worker thread? Same on Intel integrated. Add the
   raster fallback for a failed compute bake. (Godot Q4, finding 9; Neon Q3.)
5. **Low-core CPUs and battle-end join.** On 4 threads, how often does a kill end in the no-pieces pop, and how long is
   the exit join? Overlap with issue 1395 (death main-thread costs). (Godot Q5, finding 7.)
6. **VRAM at Max, 4K.** Peak on an 8 GB card with 4x MSAA, 4096 shadow atlas, sky and planet maps (up to 24 cached) and
   4K hull textures. (Godot Q6.)
7. **Coroutines after the battle is freed.** Quit to title during the enemy turn: _threat_busy is never cleared in
   _exit_tree and _runner awaits get_tree() with no tree check (battle.gd:915 and :1057 on main). (Godot Q8, Neon
   referee missed 10.)
8. **Defaults for other PCs.** Uncapped frame rate with V-Sync forced off; is a default cap safe for captures that set
   max_fps themselves? Resolution scale and a first-launch tier. Ryan picks the defaults from pictures. (Godot Q9,
   finding 4.)
9. **Idle cost split.** Real profiler on the PC: which _process owns the idle 4 ms (ship views, fx, plates, HUD layout);
   savings from the showcase guard, cached plate nodes and static RegEx. (Godot Q10, Neon Q1.)
10. **Title showcase (#29).** Spread its build over frames and cap its quality; confirm the freeze length on real hulls.
    (Godot finding 3.)
11. **Long-run leaks.** Do campaign_ui modal rebuilds and map3d per-frame meshes leak StyleBox, ShaderMaterial or
