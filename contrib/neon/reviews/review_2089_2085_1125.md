### Direct Answer to the Alternates Question

**Yes.** Both look-bench checkouts (`$LB_HOME\tool` and `$LB_HOME\repo`) depend indefinitely on Git objects stored only in `$mirror\objects` (`repo-mirror.git\objects`), and the source mirror can later prune those objects once their remote branch is deleted or force-pushed on GitHub.

**Exactly where the dependency is created and consumed:**
1. **Creation of the alternate link:** `tools/pc/runner_common.ps1:1087-1097` (`Initialize-LookBenchCheckout`), called for `$tool` (`line 1484`) and `$repo` (`line 1494`), writes `$mirror/objects` into `.git/objects/info/alternates`.
2. **Zero-copy pin fetch (mirror hit AND mirror miss):** `tools/pc/runner_common.ps1:1125-1139` (`Fetch-LookBenchPin`) fetches from `$mirror` (`line 1126`) or `$source` (`line 1133`) into `$checkout`. Because `.git/objects/info/alternates` is active, Git stores **zero** borrowed objects locally on a mirror hit (`count: 0`, `in-pack: 0`, explicitly asserted by `contrib/opus/tools/mirror_lock_tests.js:165-166`) and **also omits ancestor commits/trees/blobs already in `$mirror/objects`** on a mirror miss (`$from = $source`). On reuse, `line 1128` (`git -C $checkout cat-file -e`) also accepts objects that exist only through `alternates`.
3. **Later reads that fail after mirror pruning:** `tools/pc/runner_common.ps1:1101` (`Get-LookBenchPin`), `1487` (`checkout -f --detach $toolPin`), `1490` (`show HEAD:docs/shots/look_bench/BASELINE.txt`), and `tools/pc/jobs/look_bench.bat:100,105,138,178,198` (`git -C "%~1" checkout -f --detach "%~2"`, running up to 1.5+ hours later between `AFTER` and `BEFORE` and across every reuse).
4. **Where the source mirror drops refs and can prune objects:** `Update-SharedMirror` (`runner_common.ps1:1064`) runs `fetch --no-auto-maintenance --prune origin`, which drops deleted remote branches so their objects become unreachable in `$mirror` (Git in `$mirror` cannot see `refs/look-bench/*` in `$LB_HOME`). Meanwhile, three other PC scripts still run `fetch --prune origin` on the exact same `repo-mirror.git` **without `--no-auto-maintenance`**: `tools/pc/jobs/ship_job.bat:144`, `tools/pc/jobs/opus_job_head.ps1:442,452,876`, and `tools/pc/overnight_export.ps1:97` (plus any manual/scheduled `git gc` or mirror rebuild).
