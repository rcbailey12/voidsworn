## 1. Repaired law text (PROPOSED)

Gold means exactly one thing in Voidsworn: the reserved Command signal color, rationed to patrons and Command UI only, and used only as a Command marker or Command UI signal. Command gold is the anchor and is not recolored. The selection ring is white and the flagship marker is a faction-coloured chevron. Gold is never a material, trim, rarity, mood, gas, or decorative adjective. All formerly gold-labeled uses are resolved as follows: Chorus trim is chitin ridge ochre, matte and non-metallic, and is never called gold; Ithar trim is pearl ivory filigree, not metallic gold; epic rarity is violet-magenta; Belt plate mood is rust and charcoal; Stellar Nursery gas is teal and rose-violet. No art, UI, doc, or QA check may use gold or gold-adjacent metallic language for those uses, and if a viewer at PC battle zoom reads any non-Command element as Command gold, the non-Command element is defective and must be changed.
