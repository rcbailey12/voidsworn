# Ship file hardlink audit

**Keep copying the ship files.** Stage 7 replaces the ship folder and its asset manifest, but its headless cache refresh rewrites `godot/gen/manifest.json` in place. On Windows, that refresh changed the SHA-256 of the source-side file in a scratch hardlink pair. Standalone cache rebuilds, copy jobs, and Godot reimport with safe save off have additional in-place writers.

Refs #1187. Reviewed `37361292a4421267f213dcb4553ec1532be229bc`. The inventory covers the checked-in writers to a project's `godot/assets/ships/` and `godot/gen/`, including launchers that install or seed those trees indirectly, and the test fixtures that exercise them. The current copier takes all of `gen/`, and skips `manifest.json`, `README.md`, `a4_props.gd`, `*.uid`, `test/`, and `previews/` under `assets/ships/`. It can copy existing `*.import` sidecars. The Stage 7 probe called `manifest_merge.install()` with a small checked-in GLB fixture and the real `build_assets.gd --ships-only` refresh on Godot 4.7.2. It isolated the publish/cache steps by supplying the fixture snapshot and a no-op readback. The builder reported one loaded ship. ## What would clear the blockers

1. Stage the cache manifest, marker, field data, and each binary scene/resource in a private file on the checkout's volume, then replace the final name. Apply this to standalone generation and the T2 writers as well as Stage 7. Keep manifest paths pointing at their final files and keep the installer rollback and readback checks.
2. Convert overwrite-capable copy routes to copy into fresh files and replace the destination names, including the fallback copy and the legacy and overlay installers. Replace or privatize a linked GLB before changing its timestamp. Apply the same rule to writes from the shared-build side, since an in-place write there reaches every linked checkout.
3. Give each checkout its own editor sidecars and keep any writable glTF extraction outputs private, or make that import path use replacement independent of the user's editor setting. Keep the cache-writing tools away from the test junctions. Then check a real Stage 7 install and editor import in a linked checkout, comparing the shared build's file list, hashes and relevant timestamps before and after.
