## What the adapter and scratch install did

[bridge_a16.py](pipeline_audit_587/bridge_a16.py) makes no design changes. It translates P, S, F, T into `c_boss`'s numeric slot order. It does not add a longitudinal joint. The final bridge record retains four or five turning child meshes per pivot; the final exporter still loses every pivot.

The recipe target uses game id `c_boss`, existing game code `C19_51`, and length 26.0. The first format probe used `corsair_A16` as its diagnostic export code; the final scratch copy uses `C19_51` so normal class selection reaches it. Both exports use the same rebuilt geometry. The final capture reports `code=C19_51`, `authored=true`, and the three transformed seams.

[capture_a16.gd](pipeline_audit_587/capture_a16.gd) adapts the existing 557 production-path probe to this one capital. It packs the copied GLB and supplies the resulting scene to ShipView's existing code entry. This bypass is labelled because the default export gate failed. The final capture uses the preserved-hierarchy adapter's export, with its report sidecar supplied, and finishes all eight pictures. Raw final stills are retained in `shots/raw/`; labelled pictures remain 1280 by 720. [publish.ps1](pipeline_audit_587/publish.ps1) makes the labels and sheet previews.

Every render/capture launch waited for GPU use below 15 percent twice. `logs/gpu_gate.log` records both readings for each launch. Heavy commands used the checkout's `tmo.bat`. Shared `build_b` tools and `work217` were not touched. No files were deleted.
