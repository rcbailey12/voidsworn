# Try the map package in Godot

Choose **New run**. On the faction and admiral screen, tick **Test new battle maps, faster ships and longer gun ranges** under **Run options**, then launch. The campaign map shows **Test map package on** or **off**. Your choice stays with that run when you save and continue. New runs start unchecked, and older saves use the standard rules.

| What you will see | What changes with the box checked |
|---|---|
| Battlefields | The board stays 30 by 22. Hourglass appears more often, Corridor gets more weight in Engagement, and Archipelago gets more weight in asteroid belts and graveyards. |
| Ships and weapons | Move speed and maximum weapon range are multiplied by 1.25 for both fleets, then rounded to the nearest whole number. |
| Ambush and bosses | Ambushers split between the north and south banks. Escorts screen bosses. |
| Hunt | The quarry starts one column in from the east edge and heads toward a point 15% of the way down the west edge. Slower hunters start closer, using each ship's speed and gun reach to set the gap. Two escorts form a screen when available. The quarry still jumps after round six. |
| Other starts | Ordinary Engagement, Hold the station, Intercept, Breakthrough, Relay and Decapitation keep their deployment rules. The first teaching battle keeps its scripted field. |

To compare the two versions, start one run with the box checked and another with it unchecked. [Map study and deployment diagrams](README.md)
