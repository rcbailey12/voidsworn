# Issue 1130

| Finding | Headless evidence and fix |
| --- | --- |
| Blocked wreck hex | A missing first piece stopped the old loader. A missing later piece also stopped it and left a one-piece cache on the next call. [The loader](../../../godot/world/world_living.gd) now checks the whole kit before publishing it and uses a solid fragment for an unusable kit. [Blocked hexes](../../../godot/world/blocker_visuals.gd) and ordinary debris read the same cache. The check loads the complete kit, then drives the blocked-hex path with first-piece and later-piece gaps. |
| Max storm row | The old Max look bench left the environment fog off. [The look bench](../../../godot/bench/look_bench.gd) and [battle](../../../godot/scenes/battle/battle.gd) now share the fog setup. The check builds the storm row, finds its fog volumes and checks that a hull added to the bench is exempt from fog. |
| Nebula bench | The old High nebula setup built two worlds and 48 ship views for a 24-unit fleet and retained the first build's time. [The scene gate](../../../godot/bench/scene_gate.gd) now runs the adapter's setup before starting and timing the battle. [The nebula adapter](../../../godot/world/nebula_bench.gd) reports the built terrain tier, seed, patches and camera. The check counts one world and one fleet on Max storm and High nebula and reads the world and FX tiers. It uses a stand-in mesh and skips turn playback. |
| Fanfare | The old player kept the victory sting playing after opening the title and the defeat sting after starting another battle. [Music playback](../../../godot/music/music_player.gd) now ends the sting on title, map, battle or stop. The result screen keeps its outro while it is open. |
| Fitted shield cache | The old key made two entries for one hull at three facing and bob combinations. It could also return the first contour for a same-bounds mesh replacement. [The fitted shield](../../../godot/fx/fx_ship.gd) keys the contour on bounds and [exterior triangles](../../../godot/fx/fx_hull.gd) in the ship's unbobbed frame. It keeps at most 48 contours and places each cached contour relative to its current core. The check compares contours, verifies the contact moves with the hull and exercises eviction. |
| Puff cleanup | Weak references showed that both the material and its texture survived the old static cleanup. [ShipView](../../../godot/render/ship_view.gd) now releases the material before the texture. The same probe verifies that both are released and can be rebuilt. |
| Gallery MSAA | High selected 4x in the old gallery and 2x in battle. [The gallery](../../../godot/fx/gallery/gallery.gd) and battle now use [one mapping](../../../godot/render/look.gd). The check compares the two viewports at Low, High and Max. |

The regressions are in [world and bench](../../../godot/world/test/audit_leftovers_check.gd), [shield and puff cleanup](../../../godot/fx/test/shield_cache_check.gd) and [music](../../../godot/music/test/music_check.gd). They run from [the Godot check list](../../../godot/tools/ci/godot_checks.txt).

The Godot game check list passed all 77 headless checks. Script and scene loading, weekly bot battle seed 360 and the A16 fixture check passed. Rules parity matched all 284 battles and their saved results. The Godot-only rules safety net passed. Campaign parity matched all 30 runs, and the separate save hand-off and Nemesis checks passed. The standing checks had 72 passes and two existing baseline results. Two of those passes came on rerun with the same Node executable copied to the temporary folder so their Windows hard-link fixtures could run.

This was a code-only lane. The checks cover scene setup, ray contacts and resource lifetimes. Visual and listening review, captures and frame timing were outside this run.
