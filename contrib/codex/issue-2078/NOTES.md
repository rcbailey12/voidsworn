# AAA UI step 0

This change supplies data for SY-A, ST-A, CM-A and AR-A. It does not build those screens or change combat math, rewards, or captain perks.

- **CaptainData.** Ships keep the record in `ship.cap`. Existing ship, reserve, fallen-roll and saved victory names and XP migrate on load. Hulls that return from a Nemesis hold also migrate. Callsigns use a faction pool keyed by captain identity without consuming a rules random draw. Portraits use one indexed face per subject from the same faction, including unframed Nemesis faces. Once that faction's pool is exhausted, an unassigned portrait stays blank so a screen can use its silhouette. Trait text comes from the existing perk descriptions.
- **CombatEvent and LostShipRecord.** `BattleAPI.combat_report()` returns the hit sequence, totals by battle ship ID, and lost fleet ships as copies. Totals count actual shield and hull spent. Existing shot effects, section damage, and XP rules are separate. The campaign adds XP actually earned at settlement. Each fleet killmail is written to `RUN.timeline` at death and holds its own captain, killer, weapon, and up to two assists. A successful Eclipse reassembly removes the fleet loss and reverses kill credit on either side, without removing the damage. The Burn Stays and Cracked Coolant Manifold now record their nonlethal hull damage. `RUN.last_battle_report` keeps the finished report for victory, defeat, and retreat.
- **PreviewOp.** `Campaign.preview_op(action, key, slot)` returns rows for `repair`, `repairAll`, `upgradeMk`, `refit` from the hold, `buyHull`, and `buyMod`. Use the ship UID for repair, Mark and fitting, the template ID for new hulls, and the stock or hold index for refits. Each row includes the cost, currency, and a disabled reason when needed. A click rebuilds and applies the same plan from current state. Single-ship repair uses the affordable points and bill, fleet repair remains all-or-nothing, and blocked refits use the named reason from `fitBlock`. The yard card reads rows by stat key and shows partial repair as `Repair 18 of 20 for 9`. The prospective hull includes an available reserve captain's perks without taking that captain.
- **Story.** `arc_context()` reads the fallen captain's faction from CaptainData, with a fallback for old rows, so story arcs can name a captain lost on a prior run again.
