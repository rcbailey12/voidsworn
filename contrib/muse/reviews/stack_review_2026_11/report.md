# AI Coding Agent Harnesses & Desktop Coding Agents — Landscape as of November 2026

**Buyer:** Solo developer, Windows 11 / PowerShell, Godot (GDScript + data files, some Blender/Python) in a public GitHub repo. Agent works locally → branch → PR, reviewed/merged by a separate Claude Opus seat on Claude Max $100/mo (must not be cannibalized). Vacancy: high-volume "workhorse" generation seat. Pain point: weekly usage caps. Comparison anchor: Kimi Code Pro $39/mo bundle vs BYOK harnesses paid per API token.

**Evidence flags:** `verified live` = page fetched fresh on 2026-11-07 via browser_open. `index` = search-index sources, mostly Oct–Nov 2026, usually 2+ consistent secondary sources summarising primary pages. Star counts in this category are moving fast and sources disagree by date — treat them as order-of-magnitude only.

## Summary — bottom line for this buyer

1. **The single most important 2026 fact: you cannot legally/technically spend the Claude Max subscription inside a third-party workhorse harness.** Anthropic technically blocked subscription OAuth in third-party harnesses on 9 Jan 2026 and wrote the ban into its Legal & Compliance terms on 19 Feb 2026. OpenCode removed its Claude-subscription plugins in v1.3.0 (Mar 2026). Any harness still offering "Login with Claude Max" is either routing through the genuine Claude Code binary/ACP (a narrower, tolerated path) or putting the Max account — the reviewer's seat — at risk of suspension. **Do not cannibalize Max this way.**
2. **OpenAI went the opposite way:** "Sign in with ChatGPT" is officially supported in OpenCode, Amp, Kilo Code, T3 Code (via Codex) and others in 2026 — but this buyer has no ChatGPT plan, and that route draws on a shared Codex allowance with weekly caps, i.e. the exact pain point being avoided.
3. **Kimi Code Pro $39/mo is a stronger incumbent than the buyer's experience may suggest — if bought on a *new* plan.** Kimi's official help centre (verified live) says new Plus/Pro/Max/Ultra plans have a rolling 5-hour limit and **no weekly limit**; only *legacy* plans retain a weekly limit. The remaining cap is a shared monthly credit pool (shared with all Kimi features, no rollover), with pay-as-you-go Extra Usage when it runs out. Critically, the Kimi Code subscription key is officially usable in *other* harnesses (OpenCode has a built-in "Kimi For Coding" provider; the endpoint speaks both Anthropic and OpenAI protocols), so the $39 buys the model allowance, not lock-in to Kimi's own CLI.
4. **The BYOK alternative is dramatically cheaper per task on open models than on Claude/GPT.** DeepSeek V4.1 Flash is $0.30/$1.20 per 1M tokens peak (half off-peak); Kimi K2.7-Code was $0.95/$4.00 but **closed to new users 31 Oct 2026 and retires end-Dec 2026** — do not build a plan on it. The durable cheap workhorses are DeepSeek V4.1 Flash / V4 Pro and Kimi K3.1 Pro ($2/$10). Published estimates put heavy BYOK use on DeepSeek Flash at single-digit dollars/month and even heavy Sonnet BYOK at $150–300/mo — i.e. the harness choice matters less than the model choice.
5. **Best-fit shortlist for this buyer:** (a) **OpenCode (MIT, desktop + TUI, Windows) + Kimi Code Pro key or DeepSeek API key / OpenCode Zen** — most adopted BYOK harness, subagents, headless mode; avoid OpenCode Go if weekly caps are the pain point (Go has 5-hour + weekly + monthly windows, though with a paid Extra Usage fallback). (b) **Crush** if native Windows/PowerShell comfort is paramount. (c) **Cline + ClinePass or BYOK** if a VS Code workflow is wanted — but ClinePass itself has a weekly limit. (d) **T3 Code** is *not* a workhorse itself — it's a free control surface over Claude Code/Codex/OpenCode etc.; useful as a supervisor UI on top of (a), not a substitute for it. (e) **DeepSeek Harness (dsh)** is the cheapest-model-native option but is an unaudited developer preview — trial only, on this public repo, with care.
6. **Dead/archived — do not adopt in Nov 2026:** Roo Code (archived 15 May 2026), Continue (discontinued Jun 2026 after Cursor acquisition), Aider (dormant — no release since Feb 2026, no commits since May 2026), Gemini CLI as a consumer product (free/Pro/Ultra sign-in ended 18 Jun 2026; successor is the closed-source Antigravity CLI with weekly limits).

## Findings

### 1. OpenCode
Free MIT terminal/desktop/IDE agent from Anomaly (formerly SST; repo moved sst/opencode → anomalyco/opencode 2 Jan 2026), 75+ providers via Models.dev, local models supported. V2 (2.0, Sep–Oct 2026) is the default download alongside maintained 1.x; desktop app for Windows/Mac/Linux with parallel-session tabs. **Zen** = pay-as-you-go gateway of tested models at (vendor-claimed) no markup: $20 top-ups (+ card fee; v2 Console packs $10/$50/$100, 4.6% + $0.31 processing), auto-reload configurable. Zen per-1M examples (Oct 2026): Claude Opus 5.5 $4/$20, Sonnet 5 $2/$10, Kimi K3 $3/$15. **Go** = $10/mo, **Go Plus** $40/mo for curated open models — `verified live` on https://opencode.ai/go (fetched 2026-11-07): FAQ confirms allowances counted over **five-hour, weekly and monthly windows**, per model, with Extra Usage credit fallback so hitting a limit need not hard-stop work, and Go works with other agents (Claude Code, Codex, Hermes, Pi validated). That weekly window makes Go a *worse* fit for this buyer than Zen/BYOK despite the low price. Windows: v1 recommended WSL; v2 ships a standalone Windows binary (no Windows package managers in v2) and the desktop app needs WebView2 — workable natively, with WSL still the smoothest path for POSIX toolchains. For a Godot project (Windows-native engine), native-binary + PowerShell should be trialled first. Git: build/plan agents, subagents, `opencode run` headless, session sharing; PR creation is via git/GitHub tooling rather than a headline built-in flow — **exact built-in PR support unverified**.

### 2. T3 Code
Not an agent and not a model: a free MIT "control surface" by Theo Browne's T3 Tools/Ping that supervises locally installed Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity, Pi etc. Launched Feb–Mar 2026; ~26K GitHub stars with pushes on 7 Nov 2026; v0.1.5 on 29 Oct 2026; nightly cadence, still 0.x — expect bugs. Desktop for Windows 10/11, web (app.t3.codes), iOS/Android. Every thread gets a git worktree, inline diff and one-click PR — arguably the nicest *supervision* layer for exactly this buyer's branch→PR workflow, and its FAQ claims it stays within the wrapped CLIs' terms because it drives their official binaries. It resells no tokens and adds no caps, but also provides no workhorse capacity: the underlying plan's caps (e.g. Claude Max weekly limits, if Claude Code is the wrapped agent) still apply in full. Verdict: optional free UI on top of the chosen workhorse, not the workhorse.

### 3. OpenRouter
Routing layer, not a harness. `Verified live` https://openrouter.ai/pricing (2026-11-07): "Inference is billed at the provider's list price on every plan. OpenRouter's fee is charged when you buy credits, 5.5% on Standard and 8% on Business"; BYOK (routing your own provider keys through OpenRouter) includes $25,000/mo of list-price inference with no fee, then 5%. No plan-based rate limits on paid models; free models 50 req/day, 1,000/day after $10 of credit purchases. **First-party "agent" products: none found that is a coding harness.** Its first-party extras are model-layer products — Fusion (launched 12 Jun 2026; a panel of models + judge + synthesizer behind the `openrouter/fusion` slug, ~4–5× the cost of one completion, aimed at deep-research/hard prompts, explicitly usable as a tool *inside* a coding agent rather than a replacement for one), Auto and Pareto-Code routers (model slugs). Harnesses that commonly pair with it: OpenCode, Cline, Kilo Code (described as OpenRouter's top consumer in 2026), Aider (via LiteLLM), Goose, Crush — essentially every BYOK harness lists it. Value for this buyer: one key/balance for Kimi + DeepSeek + Claude + GPT, fallback routing, and spend controls per key; cost is the 5.5% top-up fee vs going direct.

### 4. Aider
Apache-2.0 CLI pair-programmer, ~44–49K stars, the most git-native tool here (auto-commit per edit, `/undo`, tree-sitter repo map — relevant: a repo map helps on a mixed GDScript/data project). But 2026 activity is the story: no substantial release since v0.86.0 (Aug 2025), patch 0.86.2 on 12 Feb 2026, no commits since 22 May 2026 per multiple trackers; one review flags two unfixed CVEs in `.aider.conf.yml` handling (Oct 2026) — **CVE IDs unverified here, treat as a caution flag**. Windows installs natively via PowerShell script, but docs/reviews consistently say git integration is smoother in WSL/POSIX. Headless via `--message`; no subagents, worktrees, MCP or native PR flow. Verdict: still works, do not build a new long-term workflow on it; consider maintained forks (e.g. cecli) only with eyes open — **fork health unverified**.

### 5. Cline and Roo Code
**Cline:** Apache-2.0, ~59–71K stars, actively shipping (extension v4.1.x, CLI v3.x, desktop v0.0.4x in Oct 2026). VS Code/Cursor/Windsurf/JetBrains extension, CLI for headless/CI, desktop app (Windows in beta). Free + BYOK with inference "at cost" via Cline credits or your own keys (Anthropic, OpenAI, Google, OpenRouter, Bedrock, Kimi/DeepSeek endpoints, local). **ClinePass** ($9.99/mo, launched 29 Jun 2026): 2–5× standard-API-rate usage on ~12 curated open models (GLM-5.3, Kimi K3, DeepSeek V4 Pro, Qwen3.8 Max…) — but metered over **5-hour, weekly and monthly limits**, and no Claude/GPT/Gemini. For this buyer ClinePass reintroduces a weekly cap; Cline + direct BYOK does not. Plan/Act modes, checkpoints, per-task cost display are genuine strengths for a non-coding human reviewing results. **Roo Code:** Cline fork with custom modes/orchestration — **archived 15 May 2026, final release v3.54.0**, team pivoted to Roomote (cloud agents); its own pointers send users to Kilo Code or the ZooCode community fork. Do not adopt Roo itself.

### 6. Crush (Charm)
Terminal TUI agent, ~29K stars, v0.99.0 on 29 Oct 2026, shipping frequently. License is **FSL-1.1-MIT — source-available, not OSI open source** (each release becomes MIT after 2 years); fine for a solo user's own use. Standout for this buyer: explicit first-class Windows support (PowerShell and WSL), an embedded bash interpreter so bash config behaves identically on Windows, `winget install charmbracelet.crush`. Nearly any model via OpenAI/Anthropic-compatible APIs incl. local, mid-session model switching, LSP context, MCP. Optional **Hyper** provider (open coding models, zero-retention claim): free tier 100 Hypercredits/mo; subscription $20/mo with 250 credits/day; prepaid bundles never expire; 1 credit = 5¢. Git/PR: works in the repo and via shell/gh; no headline native PR automation found — **unverified beyond git-level operation**.

### 7. Goose (Block → Agentic AI Foundation)
Apache-2.0 general-purpose local agent (coding plus automation/research), donated by Block to the Linux Foundation's AAIF in Apr 2026 (repo now aaif-goose/goose). Active: v1.56 (23 Oct 2026, incl. a proper Windows desktop NSIS installer) and v1.57 (28 Oct 2026). Desktop + CLI + API share one config; CLI on Windows installs via Git Bash/MSYS2/PowerShell with occasional manual PATH fixes — desktop is the smoother Windows path. 15+ API providers + OpenRouter + local models; via **ACP** it can drive Claude Code, Codex, Amp or Pi as sub-agents, which is how it "reuses" a Claude/ChatGPT subscription — through the vendor's own agent binary, not by extracting OAuth tokens (see §14 for why that distinction matters, and its limits). Recipes (shareable YAML workflows, runnable in CI/GitHub Actions), parallel subagents with their own model, headless runs. No paid plan and no hosted cloud agent. Fit: strong free BYOK workhorse candidate, slightly more general-purpose/less coding-specialised than OpenCode.

### 8. Amp
Built at Sourcegraph, **spun out 2 Dec 2025 as independent Amp Frontier Corporation** — calling it "Sourcegraph Amp" is now dated. Proprietary. Killed its VS Code/Cursor extensions in Feb 2026 and rebuilt the CLI in May 2026; the model is threads running on remote machines ("orbs") or your own "runners", driven from CLI/web/apps. Pricing (re-verified by trackers on 7 Nov 2026): since 13 Sep 2026 **Hobby is free** — all features, BYOK or linked subscriptions with **no Amp token fees** (outside Enterprise), your own runners free, orbs pay-as-you-go by the minute; **Megawatt $20/mo** (45,000 orb minutes), **Gigawatt $200/mo** (480,000 minutes + $200 credits). Amp-sold inference is at no markup. It officially supports linking a ChatGPT subscription. Fit caveat: Amp's centre of gravity is cloud/remote execution, whereas this buyer wants the agent on the local PC against the real (Windows/Godot) project; local runners exist, but it's a less direct fit than OpenCode/Crush, and threads are stored on Amp's servers.

### 9. Gemini CLI and Qwen Code
**Gemini CLI** (Apache-2.0): the famous free tier is over — on **18 Jun 2026 Google stopped serving free, Code Assist Individual and Google AI Pro/Ultra sign-ins**; the CLI still ships (v0.64, Oct 2026) for paid Gemini API keys, Vertex AI and Code Assist Standard/Enterprise. The consumer successor, **Antigravity CLI (`agy`)**, is closed-source, Google-account based, has a free tier with **weekly + 5-hour limits** (AI Pro $19.99/mo, AI Ultra $100/mo raise them), includes some Claude/GPT-OSS models by tier, and supports **no BYOK** — a poor match for an uncapped BYOK workhorse seat. **Qwen Code** (Alibaba, Apache-2.0, a Gemini CLI fork): CLI + desktop + IDE plugins, Windows supported, speaks OpenAI/Anthropic/Gemini-style APIs and local Ollama/vLLM — a perfectly usable BYOK harness — but its **free Qwen OAuth tier ended 15 Apr 2026**; model access is now BYOK, OpenRouter, or Alibaba's Coding/Token Plans (~$50/mo Coding Plan Pro figure appears in secondary sources with regional/availability caveats — **exact current international price unverified**).

### 10. DeepSeek Harness (dsh)
DeepSeek's own MIT-licensed harness, released as a **developer preview on 13 Aug 2026** on the Cordis plugin framework ("everything is a plugin"). Surfaces: `dsh` CLI (`npx @deepseek-ai/dsh web` → local Web UI), Electron desktop for Windows/macOS, Web UI, Python SDK, ACP server. Models: DeepSeek V4.1 Flash / V4 Pro at API prices (see §15) — the cheapest serious tokens in this survey. Release candidates through v0.2.1-rc.5 (30 Oct 2026). Warnings, all from its own docs as summarised by reviewers: compatibility-breaking changes promised, **not security-audited / not production-ready**, plugins run unsandboxed in-process, GitHub Issues disabled. On 31 Oct 2026 the Harness team published a separate MIT "superagent" prototype that listens to one GitHub repo and returns work as PRs — explicitly research code, not a product. Claimed star counts (203K–267K within ~3 months) are extraordinary and **not independently verified here**. Fit: the economics are ideal for a high-volume seat on a *public* repo, and DeepSeek models can equally be driven from OpenCode/Cline (DeepSeek's own API docs list Claude Code, Codex and OpenCode as supported front ends) — so the buyer can get dsh's model prices without dsh's preview risk. Trial dsh itself only in a throwaway environment.

### 11. Cursor and Windsurf (baseline)
**Cursor:** VS Code-fork IDE + agent/Composer, CLI and cloud agents. Pro $20/mo, Pro+ $60, Ultra $200, plus a usage pool — heavy agent use incurs overages (third-party estimates: Pro users $25–60/mo total typical, heavy sessions +$50–300). Secondary sources report SpaceX completed its acquisition of Anysphere on 14 Aug 2026 and later bundling with Grok/X plans — **ownership detail index-only**. **Windsurf is now Devin Desktop** (Cognition; rebrand Jun 2026, Cascade being wound down): Pro $20/mo, Max $200, on **daily + weekly quotas** (moved from credits in Mar 2026). Both are polished and PR-capable, but both are subscription-metered IDEs — for a non-coding human who wants a local workhorse + external review, they add an editor the buyer doesn't need and a cap structure the buyer is fleeing.

### 12. GitHub Copilot CLI / coding agent
The most native fit to a GitHub-centric workflow: Copilot plans now meter chat/agent work in **AI Credits (1 credit = $0.01, since 1 Jun 2026)** — Free (small allowance), Pro $10/mo (1,500 credits = $15), Pro+ $39 (7,000 = $70), Max $100 (20,000 = $200); completions/next-edit stay unmetered on paid plans; usage beyond the allotment can be billed. Every plan includes the Copilot CLI ( actively released, v1.0.107 on 6 Nov 2026 per index) and, on paid plans, the cloud **coding agent** (assign an issue → agent works in an ephemeral Actions environment → opens a PR) plus, from Nov 2026, cloud sandbox sessions billed against Actions compute. Strengths: zero-friction PR delivery and review integration. Weaknesses for this seat: the credit allotment is a monthly cap by another name (softer, since overage can be bought), models are GitHub's picker (Claude/GPT/Gemini etc. by plan tier), and the cloud agent does not run Godot/Blender tooling on the buyer's PC — the local CLI does, but then it's competing directly with OpenCode on BYOK economics and losing on model freedom.

### 13. Other serious harnesses
- **Kilo Code** (MIT): Roo/Cline lineage, now built on the OpenCode core; VS Code/JetBrains/CLI/cloud agents, orchestrator + subagents, zero-markup gateway and **Kilo Pass from $19/mo** (credit bundles worth more than face value at exact provider rates, per its pricing summaries). A credible Cline successor and reportedly OpenRouter's largest consumer in 2026. Windows = VS Code's Windows support. Worth a trial alongside Cline.
- **Mistral Vibe** (Apache-2.0 CLI, Devstral/Mistral models, ACP IDE support; Pro $14.99/mo): actively shipped (v3.1, 4 Nov 2026) but explicitly UNIX-targeted — "Windows is not a supported target" per its docs as summarised — skip for this buyer.
- **Zed** (GPL editor, Rust, Windows native): free with BYOK or external agents (ACP), Pro $10/mo includes $5 hosted credit with overage at list +10%. A good editor-with-agent, not a headless workhorse.
- **Continue:** discontinued — acquired by Cursor Jun 2026, final 2.0.0, repo read-only. Excluded.
- Also noted in 2026 surveys (not deep-dived; **insufficient evidence of an edge for this buyer**): Pi, OpenHands, Warp (open-sourced core May 2026), Factory Droid, Kiro (AWS), Grok Build (xAI).

### 14. Subscription sign-in policy — the cross-cutting question (critical)
**Anthropic (Claude Pro/Max): PROHIBITED in third-party harnesses, technically enforced.**
- 9 Jan 2026: Anthropic tightened safeguards; third-party tools using subscription OAuth began receiving "This credential is only authorized for use with Claude Code and cannot be used for other API requests." Anthropic's Thariq Shihipar confirmed the move publicly, citing harness-spoofing and abuse-filter bans.
- 19 Feb 2026: Claude Code *Legal and Compliance* page formalised it — quoted in multiple sources: *"Using OAuth tokens obtained through Claude Free, Pro, or Max accounts in any other product, tool, or service — including the Agent SDK — is not permitted and constitutes a violation of the Consumer Terms of Service"*; *"Anthropic does not permit third-party developers to offer Claude.ai login or to route requests through Free, Pro, or Max plan credentials on behalf of their users."* Enforcement "without prior notice"; Consumer Terms §3.7 is the cited basis.
- Mar 2026: OpenCode stopped bundling the Claude-subscription plugins (v1.3.0), stating Anthropic explicitly prohibits them. Apr 2026: the block was extended publicly to OpenClaw and "all third-party harnesses."

### 16. Harness-quality benchmarks (same model, different harness)
The best 2026 evidence is a Shandong University preprint, *"What Does a Harness Buy? Tokens, Mostly"* (arXiv:2610.04433, 3 Oct 2026): five models × three production harnesses (Claude Code 2.1, OpenCode 1.18, mini-SWE-agent 2.4.6) on SWE-bench Verified, with identical-setup reruns to establish a noise floor. Findings: harness swaps flipped ~13% of task outcomes — **the same rate as rerunning the identical harness**; on the 447-task pool the heaviest and lightest harnesses scored within ~1.4–1.8 points (statistically equivalent within 5); the one effect clearing noise was OpenCode *trailing* by up to 9 points on the large pool; and **cost per task differed up to 3×**, driven by preamble size per step (~16K tokens Claude Code, ~7K OpenCode, <1K mini-SWE-agent). Caveats: preprint, one benchmark family, closed flagship (Opus 5) ran only in Claude Code. A conflicting signal: Hugging Face's Joel Niklaus measured GLM-5.2 at 23% vs 52% on SWE-bench Pro across harnesses — suggesting harness–model *fit* (tool format a model was trained for) can matter greatly for some open models even if mature harnesses are near-equivalent for others. Practical takeaway for this buyer: pick the harness for Windows fit, workflow and cost discipline; pick the *model* for quality; and expect the same model to cost noticeably different amounts in different harnesses (favour lean-preamble harnesses / caching for a high-volume seat). No GDScript/Godot-specific harness benchmark was found — **unverified territory**; all shortlisted harnesses are language-agnostic file/shell agents, and Godot's text-based `.gd`/`.tscn`/data formats are well suited to them, but GDScript competence will track the *model*, not the harness.
