# Gold Law Repair Synthesis (chair, TWO LEGS)

Legs: contrib/qwen/reviews/gold_law_qwen38max_draft.md (Qwen3.8-Max) and
contrib/deepseek/reviews/gold_law_deepseek_draft.md (DeepSeek). Both legs
are PROPOSED draft options only. Nothing here is a ruling.

Chair verdict: GO WITH CONDITIONS. The law is repaired in substance by
both legs, and the merged table below is adoptable. The conditions are
the viewer test (which gates every RENAME-first default) and the two
confirmation checks (rarity ladder, Chorus material).

## Base text: take DeepSeek's law paragraph
DeepSeek's paragraph is the cleaner base, because it avoids both defects
the chair caught in the Qwen leg: it does not claim gold "appears as"
the white selection ring (it states the ring is white and the marker is
a faction-coloured chevron as separate facts, with gold used only as a
Command marker or Command UI signal), and it does not reference a
"Command UI colour sheet" or hue-and-value window that may not exist.
It states the rule behaviorally instead: if a viewer at PC battle zoom
reads a non-Command element as Command gold, the non-Command element is
defective and must be changed. Fold in Qwen's principle that the retired
word is replaced with a term naming the actual material or phenomenon;
DeepSeek's paragraph already carries the same idea ("Gold is never a
material, trim, rarity, mood, gas, or decorative adjective").

metallic read at battle zoom. The viewer test both legs propose is the
arbiter, so the table sets RENAME-first defaults with RECOLOR
fallbacks rather than picking one leg wholesale.

  (Qwen offered silver-steel or violet-magenta; DeepSeek picks

## Merged viewer test (the gate for every default above)
Combine the legs: two reviewers, Opus as verifier plus one artist who
did not write the repair, blind to the spec names (Qwen's blind-check
requirement, DeepSeek's reviewer composition). Conditions from
DeepSeek: 1920x1080, 100% UI scale, default combat camera distance, no
close inspection, 5 seconds per plate, each reviewer naming anything
they read as gold or as a Command marker. Scene structure from Qwen:
three scenes (one per faction trim context, one with epic-rarity loot
visible, one with the Belt or Stellar Nursery environment in the
background), each containing at least one Command gold element in the
same frame. Pass requires zero cross-flags across both reviewers and
all scenes. Any confusion is a finding against the non-Command element
and triggers that use's fallback above. RENAME alone is never a shield
if the colour still reads as Command at distance.
