## Chair-verified facts

- The hull_surface narrowing is implemented exactly as the Board's added items specified, inside the glow path rather than in check_export (whose change is header text only, since the check already keyed the exemption on each primitive's material marker): paint_stack.run() copies the glow material as p3_glow_hull with hull_surface set and gives it only to objects that are both role 'hull' and named in the stack's GLOW_HULL; the Eclipse stack's GLOW_HULL is now ('corona',) alone. Engine rings, core and lens keep the unmarked material on the same emission image, so their surfaces count for breach clearance again. The surface counts move exactly as a split predicts (E11 19 to 20 mesh primitives and 11 to 12 root surfaces; E12 16 to 17 and 10 to 11) with triangles unchanged.
- The selftest pair is a clean marker-only experiment: near_anchor_primitive duplicates the hull triangle nearest an anchor with byte-identical geometry accessors and differs only in the material marker, so hull_trim_near (pass) and part_near (fail) isolate the marker as the cause; the conditional no_trim_marker case covers exports that carry a marker. On the real exports the records match the mechanism: E11's 8 anchors pass with the trim exemption alone, and removing the marker fails exactly 3 (0.0105, 0.0199, 0.0226); E12's 4 anchors pass and removing the marker fails all 4 at 0.0000. This is what the Board's added item asked to show.
- panel_nodes implements R243 as written: one lattice from the ship's position frame, FLOOR cell ids, white-noise cell tones from the accepted PATCH_FAMILIES with unchanged shares, small panels in every fourth column (PINGPONG(column, 2) < .5 is true exactly at columns 0 mod 4), the finer grid in those columns created by doubling the axis before FLOOR with the seam distance divided back so joint width stays constant in world units, and the seam mask returned for the shared height line, which now scales it by panel_relief (.95 for Eclipse). No row offsets, no noise-chosen cell sizes, no overlay patches. The shared dispatch runs only when a stack defines panel_nodes, and the height line's .5 is now L.get('panel_relief', .5), the old constant as default.
- The Hullbreaker safety case is strong in both code and proof. In code, the dispatch and the default leave the corsair path untouched, and no corsair files appear in the PR. In proof, eclipse_642d_proof.py loads main's paint_stack.py from git as the baseline, bakes A16 under both versions on the same Blender with the same inputs, and asserts sha256 equality of every PNG. That is the right shape of proof for "no Hullbreaker look change".
