OVERALL VERDICT: NOT READY as player-facing copy. The data tables are in good shape after the round 8 rename; the failures concentrate in the help screen, the campaign meta screens, and the seams where text promises what code does not do. One genuine code bug (the shipwright repair, verified by the Argon leg and re-verified by me in campaign_run.js) sits inside a text audit because its promise is text.

1. [FIX] The help screen contradicts the game and itself. CONFIRMED verbatim: campaign_meta.js:150 states "every faction, admiral and ship is available from the start", against admiral renown costs and the LEGACY shipyard unlock gates; the very next screen text at line 151 describes unlocks, so the help is internally inconsistent as well as wrong. Same screen, same pass: line 151 promises "After each sector flagship falls, the fleet docks at a shipyard before its next fight", while afterBattle moves to the new sector map with a transit repair and no shipyard. Line 167 says "pick one of three aspects" and gives protocols "Common, Rare and Epic strength"; aspectScreen offers four aspects at mastery 2 or more, line 151 itself mentions "a fourth aspect", and RARITY includes Legendary. This is one fix batch: rewrite the help screen against the shipped systems.

2. [FIX] The rogue shipwright event repairs the wrong ship (Argon leg, chair re-verified in code). CONFIRMED: campaign_run.js's upgradeOne block heals the most damaged ship to full; the repairOne line (369) then re-sorts the fleet ascending by damage ratio and picks index 1, which after the heal is the third most damaged ship in a fleet of three or more, and the just-healed ship itself in a two-ship fleet, which then prints as fully repaired a second time while the other damaged ship gets nothing. The event text promises "a second ship is fully repaired". The only mechanical bug in this audit, and the strongest argument in it for fixing text and code together.

3. [FIX] Hull variants silently remove weapons (Argon leg, first case chair-verified). CONFIRMED for d_harvester_t: the base hull carries four weapons (data.js:100), the variant three (data.js:562), and its description mentions only the arc moving to a turret. Three more cases (i_song_w, b_razor_s, c_hulk_g) read identically from the tables. Players spend renown on these cards; the card is the contract.

4. [FIX] Shipyard and variant cards name weapons differently from ship cards (Argon leg). OBSERVED from the render code in the pack: shipyardScreen and the variants tab render base names via W[id].n, while shipCard renders the FAC_WNAMES names the player learns. The variant description texts commit the same fault in prose ("Turret laser" where the faction name is Plasma cannon; "Scatter cannons" where it is Scrap scatter gun). One naming pass over the purchase surfaces fixes both halves.

5. [FIX] The flags bug, restated from the text side (events audit finding 1). CONFIRMED in code during the events screening: five descriptions (four verb freeD lines and the saboteur face option) promise a specific choice unlocks them; the mechanism unlocks on any outcome of the gating event. The full evidence sits in the events synthesis; it is recorded here because the broken promises are player-facing text.

6. [FIX] "Carriers" wording where the game means launch ships. CONFIRMED: MODULES.hangar (data.js:165) reads "Carriers only: +1 squadron in flight" with only:'launch', while h_vanguard (Cruiser) and h_dominion (Battleship) both carry ab:'launch'; the same class error appears in ABILITIES.launch text and the Hegemony blurb ("carriers launch fighter screens"). One wording fix (launch ships) across the family.

7. [FIX] The Deathless Nemesis card promises a behaviour the code does not have. CONFIRMED in substance: beh.d says "He never retreats" and describes early reassembly; the beh object is {clock:.5, revive:1, strike:'tithe', fleet:'heavy'} with no noFlee. Prior art: the 26c Nemesis review already confirmed the mechanism side (afterBattle ordering means every faction survives a flagship kill in sectors 1-2, and a Deathless kill there spends the revive; the actual outcome is escape, "scarred and furious"). This audit adds the text side: the card asserts the opposite of the outcome the player sees.

8. [FIX] Pronoun handling is applied unevenly. CONFIRMED: nemSay exists (campaign_run.js:262) and converts beh.d (line 78) and several clock strings, but the panel line at line 80 hardcodes "His fleet is coming: your next fight is his." with no conversion, wrong on screen for female and neuter (Chorus, g:'n') Nemeses. The wider trait, weakness and adaptation descriptions were not all traced; the confirmed instance is enough to route the family.

9. [FIX] Card accuracy family. CONFIRMED as data: the hidden sqHp:.25 on the five carrier admirals (admirals audit finding 6), vaelen's global aim described as lance-scoped, kassar's damage described as accuracy. Cross-referenced rather than re-argued; the fix pass belongs with the admirals synthesis.
