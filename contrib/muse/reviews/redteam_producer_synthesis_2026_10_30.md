# Red team audit synthesis: producer seat (Oct 30, 2026)

Chair synthesis of the producer persona legs. Prongs in hand: blind Rey, DeepSeek, Argon (3 of 4). Qwen prong: PENDING FOLD-IN (daily cap at send; folds in as an addendum when it lands). Pin: main head b3a3b802.

## Seat verdict

FREEZE THE AUDITS AND SHIP THE RUN. All three prongs converge, from different directions, on the same production fact: the review apparatus now outproduces the build it reviews, the critical path to everything the settled rulings are waiting on (play data, sign-off, cutover) is one playable Godot run, and that run has exactly one implementer lane. The prongs differ on surgery, not diagnosis. Argon would stop the audits and cut pre-playable telemetry and effects research; DeepSeek re-sequences rather than cuts; the Rey leg prices the decay of every coordination artifact the program produces. The chair adopts the shared core: no new audit wave until the Godot run is playable, and the 40 failing regression tests become the agenda instead of the backdrop.

## New findings, ranked

1. **The handoff assigns nothing (Argon finding 2).** OPUS_HANDOFF states its own limit in so many words: it does not sequence implementation work, set priorities, or order builds. One implementer lane holds the 40-test backlog, the port, the battleship id choice, the anchor definition, the shield charge spec, and the reanimate gate report, with no priority order. Context-switching thrash is the predictable output, and parity work blocks behind design specs that were filed as findings.
2. **Content is stockpiled on structures already ruled defective (Rey finding 5, Argon finding 7, DeepSeek findings 4 and 9).** The filed inventory (216 tree texts, 33 event variants, 41 Nemesis lines, 16 tutorial tips, 30 framing units) is unintegrated, and integration capacity is the same single lane as everything else. Seven of the 33 events that just received variant text fail the free-exit guarantee; finished prose now sits on option structures a prior ruling found defective. The event fixes are a content gate for the full run, not polish.
3. **The scarcest resource in the project is Ryan's hands (Rey finding 7).** The evidence machine runs on static reads and sims because the real instrument is one person's play: Ryan is simultaneously the playtest source for three revisit-with-data rulings, the sign-off gate for the playable battle, and the ruling authority for every Ryan-lane question. No program document names that as a schedule risk. This synthesis does.
4. **Coordination artifacts decay in days (Rey finding 8).** The handoff is dated Oct 24 and needed a names addendum on Oct 29; this audit's own evidence base cites three reference points (main head b3a3b802, code pin 264f441d, clone head cbffcaf). At the current production rate, any document that routes work has a useful life measured in days, and the program pays a continuing tax to keep its own map readable. Fewer, load-bearing documents beat a registry that needs its own maintenance wave.
5. **Silent deletions are a pattern, and importer acceptance must price it (DeepSeek finding 5).** b_razor_s is the third silent weapon deletion. A save format where a renamed id silently deletes a ship, its captain, perks, and refits (saves audit, via Rey finding 6) plus a content pipeline that silently drops weapons is the same failure in two costumes. Importer acceptance therefore needs player-facing drop reporting and data validation, not only successful loads.
6. **Steam deferral has no exit criteria (DeepSeek finding 10).** Deferred until after Ryan plays the Godot build is a ruling; without defined playtest exit criteria the Steam date stays unestimable and platform work creeps early. Define the gate now, in one paragraph, then keep Steam out of the build until it passes.

The chair's lean is the minimal logger before first playable, full spec after, but it is your scope call.

Stakes: when the battle build is ready, the schedule of everything downstream is set by when you can sit down with it. Cost: one focused session when Opus calls it ready. The wave 5 playtest sign-off kit exists to make that session cheap; the producer seat's point is only that it should be planned, not squeezed.
