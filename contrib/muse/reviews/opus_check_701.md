## Conditions

1. **The empty-pieces fallback was removed without disclosure.** On main, when a breaking hull had wreck nodes but no pre-cut pieces, _break_up_inner kept "one pooled physical shard plus a visible ember" (spawn_debris and a spark burst), under the comment "Craft have no pre-cut job." The PR deletes that branch and substitutes the core flash plus the timed body smoke for every fall-through break-up. Wings never reach it now (they return early in _death_inner), so the exposure is any non-wing small hull that can reach break-up with empty pieces: a class without prepared buckets, or a cut job whose result is not ready at the kill frame (the code has a "fresher cut still running" path that falls back to the previous job, which may itself be empty). Such a hull would now break into light and smoke with no physical pieces at all. The report never mentions the removal. Condition: the Board confirms the branch is unreachable for non-wing small hulls and the report says so, or an equivalent fallback is restored for that case. (Blind Rey and DeepSeek, independently.)

2. **The report should disclose that the destroyer row reuses the small row's baked flash pictures.** The Done when says "destroyers no longer share the small flash row". The staging row is genuinely separate now (255 px, 0.19 s life, light reach 30.0 against small's 26.0, body 218 px), but flipbook() maps band "destroyer" back to "small" for both the material band and the staged route ("death/small/flash_"), and a code comment states the intent: "The 384 px cells cover both small rows without a rebake." The reading is defensible (the issue said bake only if a picture would otherwise be stretched, and a 384 px cell drawn at 255 px is downscaled, not stretched; the playbook defines the destroyer by size, "about 255 px, the same 1.4 step taken half way"), but the report's sentence "Destroyers use their own flash row between frigate and cruiser" does not disclose the shared atlas. Condition: one sentence in the report stating that the destroyer row has its own size, life and light reach over the small row's baked flash pictures, so the Board's acceptance of the Done-when line is informed. (Blind Rey; no other leg saw the mapping.)
