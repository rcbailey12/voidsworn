## Job 3: new names collision check

- **Ardent (the star): CLEAR.** A plain English word (burning), used as the bible claims at line 44. No game or franchise use as a star or faction name found.
- **The Ardenti (the people): MINOR ECHO.** The word exists in print in two unrelated places: Colonel Ardenti, a character in Umberto Eco's novel Foucault's Pendulum, and the Ardenti Terra indie book series by NS Scholl (https://www.smashwords.com/books/byseries/150508). Both are surnames or series titles in other genres, not a star-faring people; no game use found. No change needed.
- **The Totality: CLEAR as a name.** No game faction of this name found. One concept neighbour worth an awareness line only: Total Annihilation (1997) built its war on the same split, a side enforcing immortality by uploading against a side keeping organic bodies (Science Fiction Encyclopedia entry, https://sf-encyclopedia.com/entry/total_annihilation). The name is not used there, and Voidsworn's split is three-way and older in its own drafts; this is a shape echo, not a name collision.
- **Nadir: CLEAR.** A dictionary astronomy word (the point opposite the zenith), and it pairs with the zenith ship class the draft already uses (line 512). No franchise owns it in this sense.
- **The Siphoning: CLEAR.** A plain process word; no franchise use found.
- **The Vesper Reach: MINOR ECHO.** "Vesper" alone is in current game use as Destiny 2's Vesper Station, the setting of the Vesper's Host dungeon (2024) (https://d2.destinygamewiki.com/wiki/Vesper%27s_Host). Vesper itself is a carried name from round 4, not new; the new compound "Vesper Reach" is distinct, and Reach is a plain word. No change needed.
- **Cortical link: MINOR ECHO.** The phrase has prior generic science fiction use: Cory Doctorow's Down and Out in the Magic Kingdom (2003) wires its world in "via cortical link" (quoted in Peter Watts's Aeon essay "Hive Consciousness", https://afflictor.com/2015/05/27/the-idea-of-hooking-a-bunch-of-brains-into-a-common-network-has-a-certain-appeal/). It reads as a descriptive term, not a coined franchise term like the neural lace it replaces (line 247). No change needed.
- **Pulse laser: CLEAR.** A plain description of a real weapon type (a laser that fires in pulses), which is exactly Ryan's design note. No franchise owns it.
- **Meridian Yards: MINOR ECHO.** "Meridian" is a major Mass Effect: Andromeda location, the Jardaan's artificial sphere world that controls the vault network (https://www.polygon.com/mass-effect-andromeda-guide-walkthrough/2017/4/1/15140372/meridian-the-way-home-archon). Meridian as the Hegemony capital is carried from round 4; only the compound "Meridian Yards" (line 251) is new, and a shipyard name is a different sense. No change needed.
- **Listening Post K-7 (spotted at lines 213, 251): MINOR ECHO.** K-7 is Star Trek's Deep Space Station K-7, the station of "The Trouble with Tribbles" (The Original Series, 1967) (https://en.wikipedia.org/wiki/The_Trouble_with_Tribbles). It is a background label, not a headline name, so this is an echo, not a collision. If Ryan wants it gone, Listening Post K-12 or Post M-7 keeps the Registry's numbered feel.
- **Grand Admiral (spotted at line 248): MINOR ECHO.** A real historical rank, but in science fiction it is strongly Star Wars property through Grand Admiral Thrawn (https://en.wikipedia.org/wiki/Grand_Admiral_Thrawn). The Hegemony's own avoid list already bans Star Wars furniture (line 247), so this rank sits oddly next to it. Alternatives if Ryan wants it changed: First Admiral, High Admiral.
- **Margit (new in the Crusade pool, line 192): CLEAR.** A plain Scandinavian given name; no franchise use found.
- **Sliver and lancet (new Glasswright classes, line 448): CLEAR.** Plain words (a thin fragment; a surgical blade), in the optics and glass family by sense. No franchise use found.
- **Second Ignition (new Totality refit, line 513): CLEAR.** Plain descriptive words for a revive effect; no franchise use found.

No REAL COLLISION found among the new names.
