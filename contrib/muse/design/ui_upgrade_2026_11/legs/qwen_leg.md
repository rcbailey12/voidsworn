3. RISKS
Risk one: the loss state and a first-ever loss.
The layout is designed around victory. A loss changes the headline (from "THE CRUSADE ENDURES" to something like "THE CRUSADE FALTERS"), zeroes out some timeline figures, and removes the flagship icon. A first-ever loss means zero victories, possibly no leveled admiral, and no standout ship with kills. The design answers this by keeping every visual slot but allowing fallback content. The headline swaps to a loss variant. The timeline strip still renders with whatever numbers exist, including zeroes. The standout-ship slot becomes "most damage taken" or "last ship standing" if no kills were scored. The admiral portrait and meter still show, even at Level 1 with 0 XP. The heir block is mechanically identical regardless of win or loss, so the gate works unchanged. No slot is ever empty. It is filled with the true state, even if that state is zero.
Risk two: density and build cost at the 17 px floor.
Five key items, three heir portraits, an admiral portrait, a ship render, a timeline strip, and the action box must all fit in 1920 by 1080 with no panels to separate them, nothing under 17 px, and no overlaps. The three heir names at 28 px capitals in the center column are the tightest constraint. The design answers this with strict vertical bands (headline 0 to 120, content 160 to 560, timeline 930 to 1000) and 40 px minimum gutters between columns. The gradient does the visual separation work that panels used to do. Build cost is contained because every asset already exists: painted admiral portraits, ship renders, faction crests, the nemesis portrait pool. The new work is layout code, the hover and key wiring, and the icon set for the timeline (five small icons). No new illustration is required. The hover dialogs reuse the existing near-black square with hairline edge pattern already in the orders sheet.
Verdict: Fix the fleet and refits screen second: too many words, no ships.
