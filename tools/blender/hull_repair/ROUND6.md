# Pyre-Barge simple-paint comparison, issue 187

Double-click **RUN_PYRE_ROUND6.bat**. It queues lane A through the existing watchdog, waits while Ryan plays, and uses only the installed free tools. It never replaces a shipping asset, commits, pushes, downloads a model or generates an AI mesh.

The retained round 4 cache at `%TEMP%\voidsworn_issue146` is required. V1 opens its stage 5 Blender file and retains every triangle, including the existing 1,620 marking triangles. V3 replays `round4_hand.py` to recover separate named parts before the old script merges them. Its uncut count must match round 4. The cut deletes whole small objects and the second detail scatter. It also deletes long pipes with a diameter below half a game unit and sub-pixel weld/rivet rows. The primary hulls, large plates, engine bells, racks, guns, dishes, claws and chains stay. No collapse decimator runs. `builds.json` lists every removed object, triangle count and reason. Static parts merge at export.

`round6_material.py` supplies three coat values, local geometry AO and thin geometric edge rust. `round6_build.py` assigns them to physical masses and parts. Small V3 fittings inherit their nearest hull surface's tone; small V1 surface regions inherit the nearest major plane. Red is reserved for trim and the grouped engine banks alone emit light. There is no photo grain, mottling, rust speckle, projected art, AI albedo or donor normal. Close material crops are inspected separately. This simple recipe does not claim finished close-range richness.

The coat exports Blender specular level 0.12 as glTF specular factor 0.24. The measured runtime import left that property at Godot's 0.5 default. `round6_probe.gd` and `round6_game.gd` therefore apply the authored value to imported prototypes in the private test projects. The raw and applied values are recorded in `gpu.json` and `game_material_import.json`, and verified before sheets are delivered. Today's materials remain their own. A future shipping conversion must preserve this setting; raw GLB import alone does not reproduce these materials on this tested path.

The readable-paint standard from issue 188 merged while this job ran. Its [chair synthesis](https://github.com/rcbailey12/voidsworn/blob/main/contrib/muse/research/readable_paint_2026_11/synthesis.md) and the R105 adoption were read from main. The test uses Rec.709 weights and Gaussian sigma 7.5 at 1080p, sigma 15 at 4K. The 1080p battle record binds. Source PNGs retain native pixels; the 4K summary sheet is reduced for viewing. A white silhouette excludes the sky. Reference art uses the unchanged round 4 roll and crop, then fits each variant's projected width with aspect preserved. Neither exposure nor the histogram is matched. The unchanged round 5 colour classifier measures colour shares and median brightness. These measures do not grant visual approval.

Studio cameras, the G4 light setup, the battle radius of 170 and close radius of 49.92 are inherited from round 4. The actual-game phase uses a private copy of the current game code and live generated resources. Prototype substitution happens in memory; saves and import caches stay private. Timing restores 1920x1080, Forward+, 4x MSAA and disabled vsync, with 100 warm-up frames and 360 measured frames. Twenty ships share one mesh and map set in the same 5 by 4 layout. The 4K images are a visual record, not a 4K performance test.

Phases: `build`, `capture`, `game`, `checks`, `sheets`, or `all`. For example, `RUN_PYRE_ROUND6.bat --phase capture`. Build accepts `--route V3` or `--route V1`. The default worker scratch path is `%TEMP%\voidsworn_issue187`; `--work` must stay inside TEMP. A paint rebuild archives prior measurements and captures before replacing them. Capture rejects stale builder or recipe hashes. Use `--cache` to select another complete retained round 4 cache.

Review sheets and records go to `docs/shots/ship_pipeline/pyre_round6/` and `Downloads\voidsworn_test\board\issue-187\shots`. The issue folder also gets full studio, 4K and game PNGs, masks, final GLBs, reference images and the parity transcript. Logs, bakes and working Blender files stay in TEMP. The verifier checks GPU and camera records, export/reimport counts, V1 triangle fingerprints, authored gun axes and mount contacts, recipe hashes, PR checks and unchanged shipping inputs. Nine-cell and blur verdicts are human visual judgements recorded in the report, separate from evidence integrity.

Each nine-cell sheet also has a neutral clay version at the same cameras. This exposes construction that the dark coat can hide. The clay material is removed before ordinary captures and all benchmarks.
