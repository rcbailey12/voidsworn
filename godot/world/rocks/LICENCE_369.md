The R01 terrain was strongly warped in sphere space, combined from independent instrument fields and recoloured into mineral provinces. It is a fictional surface. Original source geography and RGB colour are not used as the result.

Each scan was centred, normalized to unit radius, converted to scan-derived vertex AO/mineral data and given a separate reduced mesh. Issue 1361 re-baked COLOR_0.b on scan_00 to scan_05 as ridge convexity (godot/world/tools/scan_facet.py) and retired scan_06 and scan_07, then scan_00 (an open-based rubble pile that drew as a torn shell from below). Original and derived file hashes are in the source receipt, r01/bake.json and scans.json.

R01 packaging, compression continuation: all three maps remain 8192 by 4096.
`planet369_pack.py` encodes WebP payloads and `planet369_pack.gd` stores them in
Godot Resources, so the game's resource export includes the data without image
import changing its channels. The 48 resources total 39,680,106 bytes, each below
8,000,000 bytes. Colour uses quality 90 compression. Height is rounded from 16 to
11 bits with at most 16/65535 error; roughness and cloud opacity are rounded to
six bits with at most 2/255 error. No spatial samples are removed. The data WebP
encoding preserves those rounded channels exactly. The loader joins tiles before
float mip generation. Descriptors record source and decoded pixel hashes and the
measured channel errors; bake.json lists every shipped resource hash and byte
count. Full original PNGs stay in TEMP. No replacement sources were downloaded.
