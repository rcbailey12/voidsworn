# Every GDScript file under godot/**/test/, one line each (issue 359 part b). GitHub fails if a file is missing here.
# Format, fields split by | with no spaces around them, never an empty field (write -):
#   class|script|setup|args|reason
# class:
#   headless  GitHub runs it: godot/tools/ci/run_checks.sh runs every headless line (setup step:... runs in its own named step)
#   gpu       needs a window, the GPU or the built ship files (godot/gen): tools/pc/jobs/godot_gpu_checks.bat on Ryan's PC
#   retired   kept in the repo but no longer a check (the reason says what replaced it)
# setup (headless): - | fixture:<tool> (node contrib/opus/tools/<tool> writes the fixtures; {fixture} in args is that file)
#   | userdir (user:// inside the checkout, the test refuses anything else) | step:<checks.yml step that already runs it>
# setup (gpu): - | env:<NAME> (NAME is set to the output folder) | envpng:<NAME> (NAME is set to <output folder>\shot.png)
#   | scene:<res path> (run that scene instead of --script) | compat (gl_compatibility renderer); several split by commas
# args: what goes after "--"; {out} is the output folder (gpu), {repo} the clone root, {fixture} the fixture file; - for none
